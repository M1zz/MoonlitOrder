🎲這是什麼 App？

月光遊戲廳是一款社交推理與派對遊戲合輯，不必連上網路，附近的 iPhone 之間直接連線就能遊玩。 只要大家在同一個 Wi-Fi 或藍牙範圍內，不需要伺服器就能馬上建立房間、加入遊戲。

▶️玩法說明

  • 輸入暱稱，選擇想玩的遊戲。
  • 由一人點一下「建立房間(房主)」，其他人透過「加入遊戲」進入房間。
  • 在同一個 Wi-Fi 或近距離（藍牙）範圍內，裝置會自動找到彼此，不需要連上網際網路。
  • 第一次連線時，需要點一下允許取用區域網路，才能找到附近的裝置。
  • 每款遊戲都可以在「玩法(與機器人練習)」中和機器人一起一步步熟悉規則。

🛠️常見問題

附近看不到房間。
請確認房主和其他玩家連接的是同一個 Wi-Fi，或彼此距離夠近。 另外，必須在「設定」>「隱私權與安全性」>「區域網路」中開啟月光遊戲廳。 同時開啟 Wi-Fi 和藍牙時，連線最穩定。
遊戲進行中斷線了。
重新打開 App 後，會自動重新連線到原本的房間，回到正在進行的那一局。 如果一段時間內沒有重新連上，請從房間列表重新加入。
最少需要幾個人？
月光結社至少需要 5 人，其他遊戲 3 人即可開始，最多可供 15 人一起玩。
需要網路或帳號嗎？
不需要。不必註冊、登入或連上網路，離線就能遊玩。遊戲資料不會傳送到伺服器。

Sammanfattning: Månarkaden har ingen registrering, inloggning, reklam eller spårning, och alla spel sker direkt mellan enheterna utan internet. Anonym användningsstatistik och felrapporter, till exempel hur många enheter appen används på, skickas till utvecklaren. Utöver det når innehåll utvecklaren bara när du själv skickar feedback från appen.

1. Inledning

Den här policyn förklarar hur Månarkaden (”appen”) hanterar dina uppgifter. Appen är en samling offlinespel för fester som ansluter enheter i närheten direkt till varandra, och den fungerar utan egen server eller konto.

2. Uppgifter som inte samlas in

Appen samlar inte in några uppgifter som kan identifiera dig, som namn, kontaktuppgifter, e-postadress, plats eller annons-ID. Eftersom det inte finns någon spelserver skickas eller lagras inga speldata externt. Anonym användningsstatistik som inte kan kopplas till dig skickas enligt punkt 5, och feedback enligt punkt 6 skickas bara när du själv skickar den.

3. Uppgifter som bara sparas på enheten

För att spelet ska fungera smidigt sparas uppgifterna nedan bara på din egen enhet. De skickas inte till någon extern server och raderas när du raderar appen.

UppgiftSyfteLagringsplats
SmeknamnNamnet som visas i spelrummetLokal lagring på enheten
Slumpmässigt enhetsnummer (UUID)Används för att återansluta dig som samma spelare om anslutningen brytsLokal lagring på enheten

Smeknamnet anger du själv, och det visas under spelets gång bara på enheter i närheten som deltar i samma spel. Enhetsnumret skapas slumpmässigt och kan inte kopplas till dig som person.

4. Användning av lokalt nätverk (anslutning till enheter i närheten)

Appen använder åtkomst till lokalt nätverk för att hitta enheter i närheten som deltar i samma spel (med Apples MultipeerConnectivity-teknik). Anslutningen sker enbart mellan deltagarnas enheter i närheten, och endast data som behövs för spelet (smeknamn, spelstatus och liknande) utväxlas. Speldata skickas inte ut via internet.

5. Anonym användningsstatistik

För att veta hur många som använder appen och för att kunna åtgärda fel skickar Månarkaden anonym statistik enligt nedan till Apples iCloud (CloudKit). Endast utvecklaren kan se den.

  • Ett slumpmässigt ID som skapas vid installationen (inte kopplat till dig, ditt Apple-ID, enheten eller andra appar; ändras om du installerar om appen)
  • Appversion, iOS-version samt inställningar för region och språk
  • Hur många gånger och vilka dagar appen har öppnats, installationsdatum och antal dagar sedan installationen
  • Felrapporter när appen hänger sig eller tvångsavslutas (appversion, iOS-version, enhetstyp och teknisk information om felet)

Namn, kontaktuppgifter, plats, smeknamn och spelinnehåll ingår inte. Statistiken skickas bara när du är inloggad på iCloud.

6. Skicka feedback

När du själv skickar feedback under Inställningar (kugghjulet) > Support skickas uppgifterna nedan till utvecklaren via den offentliga databasen i Apples iCloud (CloudKit). Ingenting skickas om du inte trycker på skicka.

UppgiftKommentar
Typ av feedback och innehållSkrivs av dig
Namn och e-postadress för svarValfritt · används bara för att svara dig
Bifogade skärmbilderBara om du väljer att bifoga dem
Appversion, enhetstyp och operativsystemversion, inställningar för språk och regionSkickas automatiskt med för att problemet ska kunna återskapas

Feedback används bara för att besvara frågor och förbättra appen. Vill du att feedback du har skickat ska raderas kan du meddela det via e-postadressen nedan.

7. Delning med tredje part och externa tjänster

Appen använder inga tredjepartstjänster, som annonsnätverk, externa analys-SDK:er eller inloggning via sociala medier, och den varken delar eller säljer dina uppgifter till tredje part. För anonym statistik och lagring av feedback används enbart Apples iCloud (CloudKit).

8. Barns integritet

Appen samlar inte in personuppgifter och kan därför användas tryggt oavsett ålder. Vi ber vårdnadshavare hjälpa barn att inte skriva personuppgifter i sin feedback.

9. Ändringar av policyn

Den här policyn kan komma att ändras till följd av ändrad lagstiftning eller ändrade funktioner i appen. Vid ändringar publiceras det uppdaterade innehållet och datumet då det börjar gälla på den här sidan.

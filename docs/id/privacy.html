Ringkasan: Arena Game Cahaya Bulan tidak memiliki pendaftaran, login, iklan, maupun pelacakan, dan semua permainan berlangsung langsung antarperangkat tanpa internet. Statistik penggunaan anonim dan laporan kesalahan, misalnya di berapa perangkat aplikasi digunakan, dikirim ke pengembang; selain itu, konten hanya sampai ke pengembang ketika Anda sendiri mengirim masukan dari aplikasi.

1. Ikhtisar

Kebijakan ini menjelaskan bagaimana Arena Game Cahaya Bulan (selanjutnya disebut “aplikasi”) memperlakukan informasi Anda. Aplikasi ini adalah kumpulan game pesta offline yang menghubungkan perangkat di sekitar secara langsung, dan berjalan tanpa server atau akun tersendiri.

2. Informasi yang tidak kami kumpulkan

Aplikasi tidak mengumpulkan informasi apa pun yang dapat mengidentifikasi Anda secara pribadi, seperti nama, kontak, email, lokasi, atau ID iklan. Karena tidak ada server game, data permainan tidak dikirim ke luar maupun disimpan di tempat lain. Statistik penggunaan anonim yang tidak dapat mengenali Anda dikirim sebagaimana dijelaskan di bagian 5, dan masukan di bagian 6 hanya dikirim ketika Anda sendiri mengirimnya.

3. Informasi yang hanya disimpan di perangkat

Agar permainan berjalan lancar, informasi di bawah ini disimpan hanya di perangkat Anda. Informasi ini tidak dikirim ke server eksternal dan akan ikut terhapus saat aplikasi dihapus.

ItemKegunaanLokasi penyimpanan
Nama panggilanNama yang ditampilkan di ruang permainanPenyimpanan lokal perangkat
Nomor acak untuk mengenali perangkat (UUID)Agar bisa tersambung kembali sebagai pemain yang sama saat koneksi terputusPenyimpanan lokal perangkat

Nama panggilan Anda masukkan sendiri dan hanya ditampilkan selama permainan di perangkat sekitar yang ikut dalam game yang sama. Nomor pengenal perangkat dibuat secara acak sehingga tidak dapat digunakan untuk mengidentifikasi Anda.

4. Penggunaan jaringan lokal (koneksi dengan perangkat di sekitar)

Aplikasi menggunakan izin akses jaringan lokal untuk menemukan perangkat di sekitar yang memainkan game yang sama (dengan teknologi Apple MultipeerConnectivity). Koneksi ini hanya terjadi di antara perangkat para pemain yang berada di dekat Anda, dan hanya bertukar data yang dibutuhkan untuk permainan (nama panggilan, status permainan, dan sebagainya). Data permainan tidak dikirim ke luar melalui internet.

5. Statistik penggunaan anonim

Untuk mengetahui berapa banyak orang yang memakai aplikasi dan untuk memperbaiki kesalahan, Arena Game Cahaya Bulan mengirim statistik anonim berikut ke iCloud (CloudKit) milik Apple. Hanya pengembang yang dapat melihatnya.

  • ID acak yang dibuat saat pemasangan (tidak terhubung dengan Anda, Apple ID, perangkat, atau aplikasi lain; berubah jika aplikasi dipasang ulang)
  • Versi aplikasi, versi iOS, pengaturan wilayah dan bahasa
  • Berapa kali dan pada hari apa aplikasi dibuka, tanggal pemasangan, dan jumlah hari sejak dipasang
  • Laporan kesalahan saat aplikasi macet atau ditutup paksa (versi aplikasi, versi iOS, jenis perangkat, informasi teknis kesalahan)

Statistik ini tidak mencakup nama, kontak, lokasi, nama panggilan, atau isi permainan. Statistik hanya dikirim jika Anda masuk ke iCloud.

6. Mengirim masukan

Jika Anda sendiri mengirim masukan di Pengaturan (ikon roda gigi) > Dukungan, informasi di bawah ini disampaikan ke pengembang melalui database publik iCloud (CloudKit) milik Apple. Tidak ada yang dikirim jika Anda tidak mengetuk kirim.

Masukan hanya digunakan untuk menjawab pertanyaan dan meningkatkan aplikasi. Jika Anda ingin masukan yang telah dikirim dihapus, beri tahu kami melalui email di bawah.

7. Berbagi dengan pihak ketiga dan layanan eksternal

Aplikasi tidak menggunakan layanan pihak ketiga apa pun, seperti jaringan iklan, SDK analitik eksternal, atau login media sosial, dan tidak memberikan atau menjual informasi Anda kepada pihak ketiga. Hanya iCloud (CloudKit) milik Apple yang digunakan untuk statistik anonim dan penyimpanan masukan.

8. Privasi anak

Karena aplikasi tidak mengumpulkan data pribadi, aplikasi ini aman digunakan oleh segala usia. Orang tua dimohon membimbing anak agar tidak menuliskan data pribadi dalam masukan.

9. Perubahan kebijakan

Kebijakan ini dapat direvisi mengikuti peraturan yang berlaku atau perubahan fitur aplikasi. Jika ada perubahan, isi terbaru dan tanggal berlakunya akan dimuat di halaman ini.
